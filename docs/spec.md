# PhotoCoach V0：可交流图片的单 Agent 摄影助手

## 1. 一句话定位

用户可以直接用文字咨询摄影问题，也可以附带照片；PhotoCoach 结合文字、图片和对话上下文，给出具体、可执行、符合用户设备与目标的摄影建议。

## 2. 目标用户

- 想学习摄影的初学者
- 使用手机或相机拍摄人像、街拍和日常照片的用户

## 3. V0 核心任务

1. 理解用户的摄影问题或拍摄目标
2. 在有图片时分析照片；没有图片时基于文字和摄影知识回答
3. 回答构图、光线、曝光、对焦、色彩和主体表达问题
4. 给出最多 3 条优先级明确的改进建议
5. 记住当前对话中的照片和用户追问
6. 在无法从图片或文字确认时明确说明不确定性

## 4. 输入

- 用户问题或拍摄目标（必选）
- 一张图片（可选；用于照片分析）
- 设备信息：手机/相机/未知（可选）
- 拍摄目标：记录/社交媒体/投稿/商业/学习（可选）
- 拍摄场景：人像/街拍/风光/静物/其他（可选）

## 5. 输出

默认回答结构：

1. 直接回答用户问题或概括拍摄目标
2. 有图片时：给出图片中的观察；无图片时：说明采用的假设
3. 最值得改进的问题（1–3 条）
4. 可执行建议（按优先级排列）
5. 如有必要，提出一个澄清问题

## 6. V0 范围

- 支持纯文字单轮和多轮摄影咨询
- 支持文字 + 单张图片的单轮和多轮对话
- 只做摄影分析和教学建议
- 只输出文字建议

## 7. V0 不做

- 自动修图或生成图片
- 多 Agent 协作
- 天气、地图、日落时间等外部工具
- 自动读取或修改相机
- 人脸身份识别、敏感属性推断
- 自动发布、分享或永久保存用户照片

## 8. 必须遵守的判断边界

- 不把无法从图片确认的快门、光圈、ISO、焦段说成事实
- 若需要精确参数，建议用户提供 EXIF
- 区分“图片中观察到的事实”和“摄影建议”
- 建议必须考虑用户设备和拍摄目标；未知时先说明假设或追问
- 不使用空泛的“很好看”，必须说明依据

## 9. 成功标准

对 10 个预设问题（包括纯文字和带图片问题），Agent 能够：

- 正确识别用户问题类型
- 有图片时至少指出一条有图片依据的观察；无图片时不假装看到了照片
- 给出不超过 3 条可执行建议
- 不虚构 EXIF 或图片中不存在的细节
- 连续追问时保持对当前图片和上下文的记忆
- 用户未说明设备时，不给出依赖具体设备的绝对操作

## 10. 第一批评测问题

1. 人像摄影怎么避免人物脸部过曝？
2. 我只有手机，怎么拍出电影感？
3. 阴天适合拍什么类型的照片？
4. 这张照片的构图怎么样？（带图片）
5. 为什么人物脸比较暗？（带图片）
6. 这张照片哪里最需要改？（带图片）
7. 如何让背景更有层次？
8. 这张照片的光线方向是什么？（带图片）
9. 你能确定我用了多少 ISO 吗？（带图片）
10. 请比较这张照片和上一张照片的区别。（多轮图片对话）
