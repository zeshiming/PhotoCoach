# PhotoCoach Intent Registry V0

## 当前设计决策

- `image_generation` 和 `image_editing` 分为两个独立意图。
- 保留 `shoot_planning`，未来可以接入小红书内容检索工具。
- 目前所有纯文字摄影问题统一归入 `photo_question`，暂不拆分器材、构图、后期等子意图。
- 以后是否拆分子意图，由评测数据和真实用户请求决定。

## Intent 列表

### `photo_question`

处理不依赖具体图片的摄影知识和技巧问题，例如相机参数、手机摄影、构图、光线、色彩和基础后期。

不负责分析具体图片、生成或修改图片，也不负责查询实时信息。

输入：纯文字即可。

Tool：V0 不需要外部 Tool。

示例：

- 快门速度怎么选择？
- 我只有手机，怎么拍出电影感？
- 阴天适合拍什么照片？

### `photo_analysis`

分析用户上传照片中的构图、光线、曝光、对焦、色彩、背景和主体表达，并给出重拍建议。

不负责确定无法从图片确认的 ISO、光圈、快门和焦段，也不负责直接修改图片。

输入：必须有图片。

Tool：后续可接 `analyze_image`、`read_exif`。

示例：

- 这张照片构图怎么样？
- 为什么人物脸比较暗？
- 这张照片最需要改哪里？

### `shoot_planning`

根据拍摄目标制定拍摄计划，包括主题、场景、时间、机位、镜头清单、器材建议和备用方案。

不负责自动预订、付款或执行不可逆操作。

输入：纯文字即可；样片为可选输入。

Tool：后续可接 `get_weather`、`get_sun_position`、`search_location` 和 `search_xiaohongshu`。

小红书工具的用途是检索公开的地点推荐、拍摄经验和网友样片参考；返回内容需要保留来源、发布时间和不确定性，不能把网友经验当成事实或实时保证。

示例：

- 周末想拍一组情侣写真，帮我规划一下。
- 我想在杭州拍一组日落人像。
- 帮我找网友推荐的上海街拍地点。

### `image_generation`

根据文字描述生成新的摄影参考图，包括构图、风格、场景、姿势和灯光参考。

输入：文字即可，也可以附带参考图。

Tool：后续接 `generate_image`。

示例：

- 帮我生成一张电影感人像摄影参考图。
- 生成一张雨天街拍构图参考。

### `image_editing`

对用户上传的已有照片进行明确修改，例如改变色调、风格、背景或光线氛围。

输入：必须有原图和明确的编辑要求。

Tool：后续接 `edit_image`。

示例：

- 把这张照片改成胶片风格。
- 把背景换成黄昏。

### `clarification`

处理意图不明确、信息不足或多个候选意图分数接近的请求。

典型情况：只有图片没有文字、同时提出分析和生成、没有说明关键拍摄目标。

Tool：不需要外部 Tool。

示例：

> 你想让我分析构图、光线、曝光，还是给出后期建议？

## Intent 冲突优先级

```text
安全和权限检查
  ↓
明确图片修改请求 → image_editing
  ↓
明确图片生成请求 → image_generation
  ↓
有图片且要求分析 → photo_analysis
  ↓
明确拍摄规划请求 → shoot_planning
  ↓
普通摄影问题 → photo_question
  ↓
无法判断 → clarification
```

## 后续拆分原则

目前不拆分 `photo_question`。当评测数据或线上 Trace 显示以下问题时，再考虑增加子意图：

- 构图问题和器材问题经常被分错；
- 不同问题需要加载完全不同的知识或 Tool；
- 单一 Prompt 变得过长；
- 不同问题的评测指标明显不同。
